# Mini Mayhem - Design Plan

> Status: **PLANNING ONLY. No code yet.** This is a living doc. We go back and forth until the foundation is solid.

## 1. Pitch [LOCKED]

A Windows desktop **survivor-like / bullet-heaven** in Unity. You move, your weapons auto-attack, enemies arrive in
waves that swell into screen-filling chaos. You collect XP and currency, level up, pick weapons and items, evolve
them, and fuse them. Between runs you spend money on permanent stats. Progress through biomes with different enemies.

Inspirations: **Survivor.io** (mobile; progression, fusion, grey-area decisions), **Brotato** (arena feel, tight
runs), and the genre in general.

## 2. Tech baseline [PROPOSED - copied from your other two games]

- Unity **6000.3.25f1**, URP, **new Input System**, TextMeshPro, (Cinemachine 3 if the camera needs it).
- Windows desktop build. **Xbox controller first-class**, keyboard/mouse also supported.
- Same project conventions as Crush Hour / Crossroot:
  - `Assets/_Project/...`, one runtime assembly, Editor assembly, EditMode + PlayMode tests.
  - **All tuning in ScriptableObjects** (weapons, items, enemies, waves, biomes, meta upgrades) so balance is edited in
    the Inspector, never in code.
  - Systems talk via a `GameServices` locator + C# events (no singletons).
  - Procedural/placeholder art and synthesised audio first; real assets can be swapped later.
  - Content generated by an editor builder where useful; JSON save in `LocalLow`.
- Performance is a **core design constraint**: hundreds of enemies + projectiles on screen. Needs pooling, no
  per-enemy physics bodies where avoidable, spatial hashing for targeting/collision, GPU instancing. Decide early (see 17).

## 3. Core loop

**Run loop (5-15 min):**
move -> weapons auto-fire -> kill enemies -> they drop XP/currency -> pickup -> level up -> choose 1 of N cards
(new weapon / new item / upgrade owned) -> waves get harder -> mini bosses -> boss -> win condition or death.

**Meta loop:** finish run -> earn meta currency (more if you survive longer / win) -> buy permanent stats -> unlock
weapons/items/characters/biomes -> start next run stronger.

## 4. Player & controls

- [LOCKED] Move-only control; **attacks are automatic**.
- [PROPOSED] Left stick / WASD = move. No manual aim by default (weapons auto-target). Optional: right stick / mouse
  can act as an aim *hint* for directional weapons (decide in 20).
- [PROPOSED] Dash/dodge: **not in v1** (keep it pure). Maybe later as a character trait.
- Pause = Start / Esc. Level-up and menus fully navigable by controller (D-pad/stick + A/B). Menu focus must always
  be visible. Mouse works too.
- Rumble on hit/level up/boss (optional, low priority).

## 5. Stats (player)

Proposed base set (also the meta-upgrade targets): Max HP, HP Regen, Armor (flat damage reduction), Move Speed,
Damage %, Attack Speed / Cooldown %, Area %, Projectile Speed %, Duration %, Pickup Radius (magnet), XP Gain %,
Currency Gain %, Crit Chance, Crit Damage, Luck (affects card rarity/drops), Revive count.
(Dodge chance deliberately skipped for now.)

## 6. Weapons [LOCKED: max 6 slots]

- Each weapon has **5 levels** [LOCKED]. Each level is a defined
  stat bump (damage, count, area, cooldown, pierce...). All data-driven.
- Weapon **archetypes** (so we can reuse code): projectile (straight/homing), orbiting, melee arc/slash, aura around
  player, boomerang/returning, ground zone/puddle, chain/lightning, summon/turret, laser beam, thrown arc/bomb.
- Targeting modes per weapon: nearest, random in range, strongest, facing direction, all-around.
- Weapons have tags (e.g. `Fire`, `Physical`, `Projectile`, `Area`) used by items and by the codex.
- **Starting weapon**: [LOCKED] free pick at run start (only unlocked weapons), no characters in v1.
- Launch target: **12 weapons** for the first build [LOCKED]; more can be added later via data.

## 7. Items (passives) [LOCKED: max 6 slots]

- Passive items modify stats and/or weapon tags (e.g. +Area, +Cooldown, +Projectile count, +Magnet).
- Each item has levels (proposed 1..5). Maxed items are the "key" for evolutions (section 9).
- Items are separate from the (future) **armour/wearables** system, which comes after this foundation is done
  [LOCKED: later phase].
- Launch target: at least 12 items (one evolution item per weapon, some shared with fusion), plus a few general stat items (Pickup Radius, Armor, Regen, Move Speed).

## 8. Level-up flow [LOCKED + PROPOSED details]

- XP bar fills -> **level up popup**, game pauses.
- Popup shows **N random cards** (proposed N = 3, raised by Luck/meta to 4). A card is one of:
  - a **new weapon** (if free weapon slot),
  - a **new item** (if free item slot),
  - an **upgrade to an already-owned** weapon/item (+1 level).
- Rule: if slots are full, only upgrades for owned things are offered (plus fallback cards, below).
- [LOCKED] "Randomly generated level up": besides XP levels, bonus level-ups can be granted (e.g. from chests/boss
  drops - **treasure chest = free level-up popup**, possibly several cards).
- [LOCKED] Utilities: **Reroll**, **Skip** (take small gold/heal instead), **Banish** (remove a card from the pool for the run).
  All start unlocked = no; they are unlocked and grown via the skill tree (section 15).
- [PROPOSED] Fallback cards when everything is maxed: "Heal", "Gold bag", "Small stat boost".
- Controller: D-pad/stick to focus a card, A to pick, Y to reroll, X to banish.

## 9. Evolutions [LOCKED rule, PROPOSED numbers]

Two kinds, each can happen **once per weapon**:

### 9a. Evolution (weapon + item)
- Condition: weapon at **max level** AND you own its **corresponding item** (any level) [LOCKED].
- Trigger: [LOCKED] a guaranteed "Evolve" card appears in the next level-up popup once requirements are met.
  This is the only way to evolve (no chest shortcut).
- Result: a stronger form of that weapon (new name, new visuals/behaviour tweak). Power roughly **equal to ~3 extra
  levels** of stats (your "a few level ups" note). Evolved weapons **do not level further**.
- Weapon keeps the slot.

### 9b. Fusion (weapon + weapon)
- Condition: **two specific max-level, non-evolved weapons** (a defined recipe pair; no free-form merging) [LOCKED].
- Trigger: a guaranteed "Fuse" card in the next level-up popup, same as evolutions.
- Result: **one fused weapon**, **frees one weapon slot**. Fusion power >= evolution (it costs two slots' worth of
  investment).
- Fused weapons can't be fused or evolved again. [OPEN] can a fused result still evolve with an item? (default: no)
- [OPEN] Can an evolved weapon be used in a fusion? (your text says "maxed leveled (not evolved)", so default: no).

### 9c. Recipes
- Defined in data: `weapon -> required item -> evolved weapon` and `weaponA + weaponB -> fused weapon`.
- The **Codex** (section 14) displays every recipe, with requirements, so nothing is a secret you must guess
  [LOCKED].

## 10. Enemies [LOCKED tiers]

Three tiers:
1. **Normal** - swarm fodder. Many types per biome.
2. **Mini boss** - tougher, special attack/behaviour, drops a chest or lots of XP.
3. **Boss** - big, scripted patterns, major reward; bosses spawn on a fixed timer [LOCKED: e.g. every 3 minutes].

- Enemies also have **levels** (scaling over time): HP/damage/speed multipliers by minute and by "danger level" of
  the match/biome [LOCKED: "different kinds and levels"].
- Behaviour archetypes: chaser, fast rusher, tank, ranged shooter, charger (telegraphed), splitter, swarm-pack,
  summoner, exploder, orbit/encircler (prevents kiting), elite variants with modifiers (shielded, regenerating, ...).
- Per-biome roster (section 12). Enemy projectiles/hazards must be readable even in chaos (clear telegraphs, colour
  language: enemy shots vs your shots).
- Drops: XP gems (tiered), currency, rare: heal, magnet (vacuum all), bomb (screen clear), chest.

## 11. Waves & pacing [LOCKED: waves, "sometimes becomes a lot"]

- A **wave director** driven by data: timeline of spawn entries (`time, enemy, count, pattern`) plus continuous
  trickle spawns scaling with time. Patterns: ring surround, line charge, pincer, cluster drop, swarm burst.
- Pacing curve: calm start -> steady growth -> **swarm spikes** (huge bursts, intentionally overwhelming) -> breather
  after boss -> next ramp. Hard cap on simultaneous enemies for performance (e.g. 400-800, tuned later) with
  graceful degradation (stronger enemies replace fodder instead of just more).
- Spawn off-screen around the player (endless maps) or at arena edges/portals (fixed arenas).
- Boss every **3:00** (match length 10+ min so ~3 bosses in a 10-min run; final boss can be the match end).

## 12. Biomes [LOCKED: ~3 matches per biome, then new one]

- Biome = enemy roster + visuals + hazards + music + possibly a map style.
- **Unlock progression**: complete (or play) **3 matches** in a biome to unlock the next. [OPEN] "play" vs "win"
  3 matches? Default: *complete* (survive objective met), not merely die.
- Each biome has its own boss(es) and mini bosses, and each is a different flavour of danger (swarmers, ranged,
  tanky, etc.).
- [LOCKED] **6 biomes** in the first build. Themes still [OPEN] (placeholders: Meadow, Swamp, Desert, Frozen, Volcano, Void/Candy). Each ~6 normal enemies, 2 mini bosses, 1 boss.
- Biome modifiers possible later (e.g. slow ground, darkness, rain).

## 13. Match types & maps

### Map styles [LOCKED: "endless expanding map OR fixed grid (mix & match)"]
- **Endless**: chunked/streamed infinite world around the player, props scattered, no walls. Enemies spawn off-screen.
- **Fixed arena (grid)**: bounded, may have obstacles/walls/hazard tiles; Brotato-like feel, enemies hug you in a box.
- **Mix**: e.g. fixed arena that **expands** (walls shrink or grow) or arena sections that open as time passes.
- Which map style goes with which biome/mode is configurable per match definition ([PROPOSED]: biome + mode +
  map style are independent data fields so we can mix freely).

### Match modes [LOCKED]
- **Survive** - stay alive until the end of the run (final boss / timer).
- **Outlast time** - survive X minutes (10 / 15 / 20; `10+` minutes).
- **Number of kills** - reach N kills before time limit (or before dying).
- [PROPOSED extras for later]: kill the boss, collect objectives, endless/high-score, daily seed.
- Each mode defines: win condition, run length, reward multiplier.

### Run end
- Win -> bonus rewards. Death -> keep a portion of earned currency (proposed 100% on win, ~50-60% on death; tuned).
- [PROPOSED] One free **revive** per run if bought in meta upgrades.

## 14. Currency, XP, drops

- **XP gems** dropped by enemies, auto-attracted within pickup radius. Tiers by colour/value.
- **In-run currency (gold)**: dropped by enemies, accumulates for the run. [OPEN] Is it *only* converted to meta
  currency at the end, or is there an in-run spend (Brotato-style shop between waves / chest keys)?
- **Meta currency**: earned at end of run from gold + kills + time survived + objectives + win bonus.
- [OPEN] Single meta currency, or two (common gold + rare gems for unlocks)?
- Drops of note: **Magnet** (pulls all gems/coins on the map) and **Health** boost spawn randomly during the run [LOCKED]. Pickup radius is a stat only. Chest (free level-up popup) from mini bosses/bosses. Bomb (screen clear) [PROPOSED].

## 15. Meta progression [LOCKED: buy passive stats]

- **Permanent upgrades shop** (spend meta currency): Max HP, HP Regen, Damage/Attack, Move Speed (your list), plus
  Pickup Radius, XP Gain, Currency Gain, Luck, Armor, Reroll/Banish/Revive counts.
- [LOCKED] The meta shop is a **skill tree**: you start at a root node and each unlocked node opens branches to others.
  Nodes are data (`SkillNodeDefinition`: id, cost, max rank, prerequisites, effect, position in the tree).
- [PROPOSED] Branches (names tentative): **Vitality** (Max HP, Regen, Armor, Revive, death-keep % ), **Might** (Damage, Attack Speed,
  Crit, Area), **Swift** (Move Speed, Pickup Radius, XP Gain), **Fortune** (Gold Gain, Luck, Reroll/Skip/Banish unlocks and counts,
  extra card slot at level-up).
- Gated nodes: **Reroll, Skip, Banish, Revive** each start locked; unlocking gives 1 use, further ranks add more.
- **Death keeps 50% of gold** by default; nodes raise it (up to a cap, e.g. 80%).
- Each node costs gold with an escalating curve (`cost = base * growth^rank`); deeper nodes cost more.
- UI: pannable/zoomable tree, controller-friendly (stick moves focus node to node, A buy, B back), shows prerequisites and effect before buying.
- Weapon/item/biome unlocks are NOT in the tree (they come from play progress and achievements) to keep the tree about power only.
- [PROPOSED] Full respec/refund allowed at any time (no punishment for trying).
- Unlocks (separate from stats): new weapons, items, characters, biomes, match modes. Some gated by achievements.

## 16. Codex / Info page [LOCKED]

A dedicated screen in the main menu:
- Tabs: **Weapons, Items, Evolutions, Fusions, Enemies, Biomes, Stats**.
- Per weapon: description, how it works (targeting, archetype), stats per level, what item it evolves with, the
  evolved form, which fusions it takes part in, and **how to unlock** it.
- Per item: effects per level, which weapons it evolves.
- Recipes view: "A + B -> C", "Weapon + Item -> Evolved", with check marks for owned/seen.
- [PROPOSED] Entries are **hidden as "???" until discovered**, but recipe *requirements* are always visible once the
  weapon is discovered (so you can plan runs). [OPEN] or show everything from the start?
- Generated automatically from the same ScriptableObjects, so it can never go out of date.

## 17. Technical architecture notes (to decide before building)

- **2D vs 3D** [OPEN]: top-down 2D (sprites/quads) vs 3D models with a fixed top-down/isometric camera. Procedural
  art fits both; 3D matches Crush Hour, flat 2D is cheaper per enemy.
- **Enemy simulation**: pure-data/ECS-style or DOTS Entities for thousands of units vs. pooled GameObjects with
  custom (non-physics) movement + spatial hash. Default proposal: **pooled GameObjects, custom movement/collision
  with spatial hash, GPU-instanced rendering**; revisit DOTS only if profiling demands it.
- Projectiles & damage numbers & gems all pooled; caps and merging (many gems merge into one big gem).
- Data layer: ScriptableObjects: `WeaponDefinition`, `ItemDefinition`, `EvolutionRecipe`, `FusionRecipe`,
  `EnemyDefinition`, `WaveTimeline`, `BiomeDefinition`, `MatchDefinition`, `MetaUpgradeDefinition`, `CharacterDefinition`.
- Run state machine: Menu -> Run Setup -> Running -> LevelUpPause -> BossIntro -> Win/Lose -> Results -> Meta shop.
- Save: JSON (meta currency, upgrades, unlocks, biome progress, codex discovery, stats, settings).
- Tests: EditMode for data/recipe validation (no recipe references a missing weapon, etc.), PlayMode with virtual
  gamepad like in Crush Hour.
- Settings: resolution, volume, controls, damage-number toggle, screen-shake toggle, colour-blind enemy outlines.

### 22.6 Match structure
- Each biome has 3 matches that must be **completed** to unlock the next biome. Map style alternates: Biome 1 Endless/Fixed/Endless, Biome 2 Fixed/Endless/Fixed, and so on.
- Mode is random per match: **Survive** (stay alive to the 10:00 finale boss), **Outlast Time** (survive to 10:00), **Kill Count** (reach N kills before dying; N scales per biome).
- Each match shows its mode and map style on the pre-run screen. Reward multiplier per mode is data.
- [PROPOSED] Replaying completed matches is always allowed (farming currency) and re-rolls mode/map each time.

### 22.7 Skill tree (draft node list)
Each node: ranks 1..N, cost escalates; prerequisites branch outward from the root ("Mayhem Core").
- **Vitality**: Max HP, HP Regen, Armor, Revive (unlock, then +1 use per rank, once per run at first), Death-keep % (50 -> 80).
- **Might**: Damage, Attack Speed, Crit Chance, Crit Damage, Area.
- **Swift**: Move Speed, Pickup Radius, XP Gain, Projectile Speed.
- **Fortune**: Gold Gain, Luck, Reroll (unlock then +uses), Skip (unlock then +uses), Banish (unlock then +uses), Level-up card count 3 -> 4 (late, expensive).
Branch gating idea: Revive and Death-keep sit deep in Vitality; Reroll/Skip/Banish are mid-depth in Fortune; the +1 card slot is a late Fortune node.

### 22.8 Pacing & numbers (starting values, all tuneable)
- Match 10:00. Bosses at 3:00, 6:00, 9:00 (the 9:00 boss is the "finale" in Survive mode; Outlast just continues to 10:00).
- XP to level: gentle early curve so first 5 weapon picks happen in ~2 minutes; total ~25-30 level-ups in a 10 minute run.
- Enemy caps on screen: start at ~300, raise after profiling. Swarm bursts at roughly 2:30, 5:00, 7:30, 9:30.
- Drops: magnet and health spawn on a random timer (roughly every 45-90 seconds each), mini bosses and bosses drop a chest (free level-up popup).

### 22.9 Weapon/item unlock [PROPOSED]
Start with 4 weapons unlocked (Pea Shooter, Frying Pan, Duck Orbit, Star Wand) and the 7 general items. The other 8 weapons unlock by clearing biomes (one or two per biome) so each new biome also brings new tools. Their evolution items unlock together with the weapon.
